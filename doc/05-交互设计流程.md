## 三、关键交互细节

### 3.1 身份校准交互

```
场景：用户在时间轴中发现某条消息的身份标记错误

交互：
1. 用户右键点击消息
2. 弹出菜单：[这是我的消息] [这是对方的消息] [我不确定]
3. 用户选择后：
   - 如果是昵称变更导致的 → 提示"是否将『旧昵称』的所有消息都归给用户A？"
   - 如果是单次错误 → 仅修改这一条
4. 修改后：
   - 重新计算相关统计数据
   - 如果影响情绪曲线，提示"数据已更新，是否刷新图表？"
```

### 3.2 情绪修正交互

```
场景：AI 对某条消息的情绪判断错误

交互：
1. 用户点击消息旁的情绪标签（如 "😟 负面"）
2. 弹出情绪选择面板：
   ┌────────────────────────┐
   │ 修正情绪标签            │
   │                        │
   │  😊 正面    😐 中性    │
   │  😟 负面    😠 愤怒    │
   │  😢 悲伤    💕 亲昵    │
   │  🙄 敷衍               │
   │                        │
   │  [取消]  [确认]        │
   └────────────────────────┘
3. 用户确认后：
   - 更新数据库中的情绪标签
   - 标记为"用户修正"（用于后续改进 AI Prompt）
   - 局部刷新情绪曲线（仅重算受影响的时间段）
```

## 四、响应式断点

```
桌面端 (>= 1280px)
  - 仪表盘：3列卡片布局
  - 时间轴：左侧曲线 + 右侧详情
  - AI 对话：左侧快捷问题 + 右侧对话区

平板端 (768px - 1279px)
  - 仪表盘：2列卡片布局
  - 时间轴：上下布局
  - AI 对话：全宽对话区，快捷问题折叠

移动端 (< 768px)
  - 仪表盘：单列堆叠
  - 时间轴：全屏图表，点击后全屏详情
  - AI 对话：简化布局，底部固定输入框
```

## 五、异常状态处理

| 场景 | 处理方式 |
|------|----------|
| 导入文件过大（> 100MB） | 分块解析，显示进度条，可后台处理 |
| 解析格式无法识别 | 显示错误详情 + 建议的导出方式 |
| AI API 调用失败 | 自动降级到规则分析 + 提示用户 |
| 数据库写入失败 | 提示清理浏览器存储空间 |
| 身份全部识别为 unknown | 强制弹出身份选择弹窗，阻塞后续流程 |
| 消息量过少（< 50条） | 提示"消息量较少，分析结果可能不够准确" |
| 检测到单聊但参与者 > 2 | 提示"检测到群聊，暂不支持群聊分析" 或切换到群聊模式 |
