## v0.2.0 - 2026-05-16

### 新增功能

#### 关系健康度评分
- **文件**: `src/analyzers/relationship-score.ts`
- **说明**: 综合五维指标计算 0-100 分健康度
  - 互动平衡度（25%）：消息量是否对等
  - 情绪正向度（25%）：正面 vs 负面情绪比例
  - 回复及时性（20%）：平均回复延迟
  - 互动稳定性（15%）：近 30 天 vs 前 30 天消息量变化
  - 聊天深度（15%）：平均消息长度
- **展示位置**: DashboardView 仪表盘顶部，含进度条和五维标签

#### 危险信号检测
- **文件**: `src/analyzers/danger-signals.ts`
- **说明**: 自动检测 5 类关系预警信号
  1. **倾诉不对等**：一方消息量超过 70%
  2. **连续沉默期**：超过 7 天无交流
  3. **负面表达激增**：近 30 天负面词汇是前 30 天的 2 倍以上
  4. **敷衍回应增多**：近 30 天 indifferent 情绪占比超过 30%
  5. **回复速度持续下降**：近期平均回复时间是早期的 2 倍以上
- **展示位置**: DashboardView 仪表盘，按严重程度（高/中）用 Alert 展示

#### Ollama 本地 AI 支持
- **文件**: `src/ai/ollama.ts`, `src/components/ModelConfig/ModelConfigDialog.vue`
- **说明**: 自动检测本地 Ollama 服务，无需 API Key 即可使用本地大模型
  - 检测端口: `localhost:11434`
  - 自动拉取本地已安装的模型列表（含模型大小）
  - 在模型配置面板一键添加本地模型
  - 支持 `qwen2.5:7b`, `qwen2.5:14b`, `deepseek-r1:7b`, `llama3.2` 等预设
  - AI 调用时自动跳过 Authorization header，完全兼容 Ollama 的 OpenAI 兼容接口

#### 关键词追踪
- **文件**: `src/analyzers/keyword-track.ts`, `src/views/AnalysisView.vue`
- **说明**: 在深度分析页面追踪任意关键词在聊天记录中的出现趋势
  - 输入关键词后按天聚合双方使用次数
  - 柱状图展示关键词使用趋势对比
  - 列出所有匹配消息，含前后各2条上下文
  - 高亮显示关键词（`<mark>` 标签）
- **展示位置**: AnalysisView 深度分析页面顶部

#### 消息情绪修正
- **文件**: `src/views/TimelineView.vue`, `src/views/MessageListView.vue`, `src/stores/session.ts`
- **说明**: 用户可手动修正单条消息的情绪标签
  - 在时间轴详情和消息列表中点击情绪标签即可修正
  - 弹出 7 种情绪选择面板，当前情绪高亮显示
  - 用户修正过的消息标记 ✎ 标识
  - 修正后自动重新计算情绪趋势曲线
  - 数据库记录 `emotionMethod: 'user'` 区分规则标注与用户修正
- **价值**: 提升情绪分析准确度，让用户参与校准

#### 关系阶段判定
- **文件**: `src/analyzers/relationship-stage.ts`, `src/views/DashboardView.vue`
- **说明**: 基于统计数据自动判定关系所处阶段
  - 五阶段模型：蜜月期 / 稳定期 / 倦怠期 / 危机期 / 修复期
  - 规则引擎实现（基于消息频率、情绪比例、回复延迟、消息长度、前后对比）
  - 检测危机信号（沉默期、负面情绪激增、倾诉不对等、回复速度下降）
  - 检测修复信号（消息长度增加、正面情绪上升、回复加快）
  - 展示在仪表盘顶部，含置信度和关键指标标签
- **当前实现**: 规则引擎版，后续可接入 AI 模型提升准确度

#### AI 脱敏模块
- **文件**: `src/ai/sanitizer.ts`
- **说明**: 为后续 AI Function Calling 做准备的脱敏工具
  - 替换手机号、微信号、身份证、银行卡、邮箱、地址
  - 支持消息截断和发送者匿名化（用户A/用户B）
- **当前状态**: 模块已创建，待 Function Calling 接入时启用

### Bug 修复

#### 回复延迟计算逻辑
- **文件**: `src/analyzers/statistics.ts`
- **问题**: 原算法逐条对比 `prev.isSelf !== curr.isSelf`，导致同一轮次内连续消息的间隔被错误计入回复延迟
- **修复**: 改为按"对话轮次"计算，只统计轮次切换时的真实回复间隔
- **新增字段**: `avgSelfReplyDelay`（我方平均回复时间）、`avgOtherReplyDelay`（对方平均回复时间）

### UI 改进

#### 仪表盘增强
- 新增关系健康度卡片（含进度条 + 五维细分标签）
- 新增危险信号预警区域（红色/黄色 Alert）
- 危险信号按严重程度排序，高危优先展示

#### 报告导出
- **文件**: `src/views/ReportExportView.vue`, `src/utils/export.ts`
- **说明**: 支持将分析报告导出为 PDF 或图片
  - 配置选项：报告类型（简要/完整）、时间范围（全部/近30天/近90天/自定义）、隐私脱敏开关
  - 报告内容：数据概览、关系健康度、危险信号、情绪趋势图、免责声明
  - 使用 `html2canvas` 截图 + `jsPDF` 生成多页 PDF
  - 新增侧边栏"报告导出"入口
