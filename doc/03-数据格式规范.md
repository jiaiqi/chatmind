## 一、内部数据模型

### 1.1 消息 (Message)

```typescript
interface Message {
  /** 全局唯一 ID */
  id: string;
  
  /** 所属会话 ID */
  sessionId: string;
  
  /** 发送者内部 ID */
  senderId: string;
  
  /** 是否为分析者本人 */
  isSelf: boolean;
  
  /** 消息时间戳（毫秒） */
  timestamp: number;
  
  /** 消息内容 */
  content: string;
  
  /** 消息类型 */
  type: MessageType;
  
  /** 情绪标签（预计算） */
  emotion?: EmotionLabel;
  
  /** 情绪置信度 */
  emotionScore?: number;

  /** 情绪标注方式：rule = 规则引擎自动标注，user = 用户手动修正 */
  emotionMethod?: 'rule' | 'user';

  /** 消息长度（字符数） */
  wordCount: number;
}

type MessageType = 
  | 'text'      // 文本消息
  | 'image'     // 图片
  | 'voice'     // 语音
  | 'video'     // 视频
  | 'file'      // 文件
  | 'location'  // 位置
  | 'link'      // 链接
  | 'system'    // 系统消息
  | 'transfer'  // 转账
  | 'redpacket' // 红包
  | 'emoji'     // 表情包（纯表情，无文字）
  | 'unknown';  // 未知类型

type EmotionLabel = 
  | 'positive'     // 正面
  | 'negative'     // 负面
  | 'neutral'      // 中性
  | 'angry'        // 愤怒
  | 'sad'          // 悲伤
  | 'affectionate' // 亲昵
  | 'indifferent'; // 敷衍/冷淡
```

### 1.2 参与者 (Participant)

```typescript
interface Participant {
  /** 内部唯一 ID */
  id: string;
  
  /** 微信 ID（可能缺失） */
  wxid?: string;
  
  /** 所有出现过的名称（昵称/备注名） */
  names: string[];
  
  /** 角色 */
  role: 'self' | 'other' | 'unknown';
  
  /** 消息数量 */
  messageCount: number;
  
  /** 首条消息时间 */
  firstSeen: number;
  
  /** 末条消息时间 */
  lastSeen: number;
}
```

### 1.3 会话 (Session)

```typescript
interface Session {
  /** 会话唯一 ID */
  id: string;
  
  /** 会话名称（对方昵称/群名） */
  name: string;
  
  /** 会话类型 */
  type: 'private' | 'group';
  
  /** 参与者 ID 列表 */
  participantIds: string[];
  
  /** 导入时间 */
  importedAt: number;
  
  /** 消息总数 */
  messageCount: number;
  
  /** 时间范围 */
  timeRange: [number, number]; // [firstMessageTime, lastMessageTime]

  /** 导入格式标识 */
  sourceFormat: string;

  /** 原始文件名 */
  sourceFileName: string;
}
```

### 1.4 事件 (Event)

```typescript
interface Event {
  /** 全局唯一 ID */
  id: string;

  /** 所属会话 ID */
  sessionId: string;

  /** 事件日期 YYYY-MM-DD */
  date: string;

  /** 事件类型 */
  type: string;  // 自动检测: emotion_peak / silence_end / volume_spike / argument
                 // 手动标记: milestone / 用户自定义

  /** 事件标题 */
  title: string;

  /** 事件描述 */
  description: string;

  /** 严重程度 */
  severity: 'low' | 'medium' | 'high';

  /** 是否自动检测生成 */
  isAuto: boolean;

  /** 创建时间 */
  createdAt: number;
}
```

### 1.5 身份图谱 (IdentityGraph) — 未实现

> 注：当前版本的身份识别逻辑直接由 `src/stores/identity.ts` 管理，未采用独立的 IdentityGraph 数据结构。曾用名信息存储于 `DbParticipant.names` 数组中。

## 二、导入格式规范

### 2.1 WeFlow JSON 格式（推荐）

WeFlow 导出的标准格式，信息最完整。

```json
{
  "version": "1.0",
  "source": "weflow",
  "exportTime": "2026-05-15T10:30:00Z",
  "session": {
    "name": "张三",
    "type": "private",
    "wxid": "wxid_xxxxxxxxxxxxxxxx"
  },
  "participants": [
    {
      "wxid": "wxid_xxxxxxxxxxxxxxxx",
      "displayName": "张三",
      "remarkName": "老张",
      "role": "other"
    },
    {
      "wxid": "wxid_yyyyyyyyyyyyyyyy",
      "displayName": "我的昵称",
      "role": "self"
    }
  ],
  "messages": [
    {
      "timestamp": 1715731200,
      "senderWxid": "wxid_yyyyyyyyyyyyyyyy",
      "senderName": "我的昵称",
      "content": "在吗",
      "type": "text"
    },
    {
      "timestamp": 1715731250,
      "senderWxid": "wxid_xxxxxxxxxxxxxxxx",
      "senderName": "张三",
      "content": "在的",
      "type": "text"
    }
  ]
}
```

### 2.2 WeFlow CSV 格式

```csv
timestamp,senderWxid,senderName,content,type
1715731200,wxid_yyyyyyyyyyyyyyyy,我的昵称,在吗,text
1715731250,wxid_xxxxxxxxxxxxxxxx,张三,在的,text
```

### 2.3 通用 TXT 格式（兼容）

支持多种常见格式自动识别：

**格式 A（微信自带备份导出）**
```
2024-03-15 10:23:15 张三
在吗

2024-03-15 10:24:30 我的昵称
在的，怎么了？
```

**格式 B（带括号时间）**
```
[2024-03-15 10:23:15] 张三: 在吗
[2024-03-15 10:24:30] 我的昵称: 在的，怎么了？
```

**格式 C（简单时间）**
```
10:23 张三: 在吗
10:24 我的昵称: 在的
```

### 2.4 通用 HTML 格式（兼容）

解析微信导出的 HTML 文件，提取其中的消息结构。

## 三、导出格式规范

### 3.1 分析报告 PDF

```
封面: ChatMind 关系分析报告
      分析对象: [会话名称]
      分析时间范围: [日期范围]
      生成时间: [日期]

目录:
  1. 数据概览
  2. 聊天趋势分析
  3. 情绪分析
  4. 关系洞察
  5. 建议

附录:
  - 数据说明
  - AI 免责声明
```

### 3.2 数据导出 JSON

用于用户备份或迁移：

```json
{
  "version": "chatmind-v1",
  "exportedAt": "2026-05-15T10:30:00Z",
  "sessions": [
    {
      "id": "session-xxx",
      "name": "张三",
      "type": "private",
      "participants": [...],
      "messages": [...],
      "analysis": {
        "statistics": {...},
        "emotion": {...}
      }
    }
  ]
}
```

## 四、与 WeFlow 的协作规范

### 4.1 推荐的协作流程

```
[用户安装 WeFlow]
     ↓
[WeFlow 解密微信数据库]
     ↓
[WeFlow 导出为 JSON（选择 ChatMind 格式）]
     ↓
[用户打开 ChatMind]
     ↓
[拖拽 JSON 文件到 ChatMind]
     ↓
[ChatMind 解析并分析]
```

### 4.2 HTTP API 对接（未来）

如果 WeFlow 开启 HTTP API：

```typescript
// 调用 WeFlow API 获取会话列表
GET http://127.0.0.1:5031/api/v1/sessions

// 调用 WeFlow API 获取指定会话消息
GET http://127.0.0.1:5031/api/v1/sessions/{sessionId}/messages
```

### 4.3 建议的 WeFlow 格式扩展

建议 WeFlow 在导出时包含以下元数据：

```json
{
  "_meta": {
    "exportTool": "weflow",
    "exportToolVersion": "4.2.1",
    "wechatVersion": "4.0.3",
    "encrypted": false,
    "encoding": "utf-8"
  },
  "participants": [
    {
      "wxid": "wxid_xxx",
      "displayName": "昵称",
      "remarkName": "备注名",
      "avatar": "base64或URL",
      "isSelf": true  // 明确标记是否本人
    }
  ]
}
```

## 五、数据转换流程

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  原始文件     │ --> │  格式解析器   │ --> │  RawMessage  │
│ (JSON/CSV/   │     │  (Parser)    │     │  (标准化)    │
│  TXT/HTML)   │     │              │     │              │
└──────────────┘     └──────────────┘     └──────┬───────┘
                                                  │
                                                  ↓
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  分析结果    │ <-- │  分析引擎     │ <-- │  Identity    │
│  (可视化)    │     │  (Analyzer)  │     │  Resolution  │
└──────────────┘     └──────────────┘     └──────────────┘
                                                  ↑
                                           ┌──────┴───────┐
                                           │  用户确认    │
                                           │  身份映射    │
                                           └──────────────┘
```
