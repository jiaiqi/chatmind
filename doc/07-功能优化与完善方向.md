## 二、待完善功能清单

### 2.1 高价值 · 低复杂度（推荐近期优先）

这些功能实现成本不高，但能显著提升用户体验或补齐 PRD 规划。

#### 1. 消息情绪修正
- **需求来源**: PRD 3.3.1、交互设计 3.2
- **说明**: 用户在时间轴或消息列表中点击情绪标签，手动修正单条消息的情绪。修正后局部刷新图表。
- **价值**: 提升情绪分析准确度，让用户参与校准；收集数据可用于后续改进 AI Prompt。
- **涉及文件**: `src/views/TimelineView.vue`、`src/views/MessageListView.vue`、`src/db/schema.ts`（增加 `emotionMethod: 'rule' \| 'user'`）

#### 2. 聊天时段迁移分析
- **需求来源**: PRD 3.3.1 基础层
- **说明**: 对比前期和后期的活跃时段分布，检测"从深夜畅聊到白天敷衍"的模式变化。
- **价值**: 直观展示关系冷却的一个侧面指标。
- **涉及文件**: `src/analyzers/statistics.ts`（新增时段对比）、`src/views/AnalysisView.vue`（新增图表）

#### 3. 身份校准（消息级修正）
- **需求来源**: PRD 3.2.2 第三层、交互设计 3.1
- **说明**: 在消息列表中右键/点击切换单条消息的身份归属；支持"将某昵称的所有消息批量归给用户A"。
- **价值**: 解决导入后发现的少数身份误判，提升数据准确性。
- **涉及文件**: `src/views/MessageListView.vue`、`src/stores/session.ts`

#### 4. AI 回答可溯源（引用原始消息）
- **需求来源**: PRD 1.3 "可溯源"
- **说明**: AI 回答中如果引用了具体消息，渲染为可点击链接，点击后跳转到对应时间点的聊天记录。
- **价值**: 核心卖点之一，让 AI 结论有据可查，增强可信度。
- **涉及文件**: `src/views/AiChatView.vue`、`src/stores/ai.ts`

#### 5. 快捷问题扩展
- **需求来源**: 当前仅 5 个固定快捷问题
- **说明**: 增加更多场景化快捷问题，如"谁更主动发起聊天？""最近一次争吵是什么时候？""我们的聊天高峰是什么时候？"
- **价值**: 降低用户使用 AI 的门槛，引导发现数据洞察。
- **涉及文件**: `src/views/AiChatView.vue`

### 2.2 高价值 · 高复杂度（中期规划）

这些功能能显著提升产品差异化，但需要较多设计和开发时间。

#### 6. AI Function Calling（工具调用）
- **需求来源**: AI-Prompt 设计文档 3.1、PRD 3.4.1 交互层
- **说明**: 让 AI 可以调用工具查询数据（query_messages、query_emotion_trend、query_statistics、search_keywords、compare_periods）。AI 不再只依赖预注入的统计摘要，而是能按需查询。
- **价值**: 从"静态报告"升级为"动态分析师"，回答更精准、可交互。
- **涉及文件**: `src/ai/tools/`（新建）、`src/ai/client.ts`（支持 tools 参数）、`src/ai/sanitizer.ts`（启用脱敏）
- **依赖**: 脱敏模块 `src/ai/sanitizer.ts` 已创建，需接入启用

#### 7. 关系阶段判定
- **需求来源**: PRD 3.3.1 高阶层、AI-Prompt 设计 2.4
- **说明**: 基于统计数据自动判定关系所处阶段（蜜月期/稳定期/倦怠期/危机期/修复期），并给出置信度和依据。
- **价值**: 给用户一个直观的"关系体检结果"，是产品的核心差异化功能。
- **涉及文件**: `src/analyzers/relationship-stage.ts`（新建）、`src/views/DashboardView.vue`（展示阶段标签）
- **实现路径**: 可先用规则引擎（基于消息量、回复延迟、情绪比例等阈值），后续升级为 AI 判定

#### 8. 情绪感染度与修复时间
- **需求来源**: PRD 3.3.1 进阶层
- **说明**:
  - 情绪感染度：当一方表达负面情绪后，另一方在后续 N 条消息内是否也出现负面情绪。
  - 情绪修复时间：一次负面事件（连续负面情绪）后，多久恢复正面交流。
- **价值**: 揭示关系中的"情绪互动模式"，是专业心理咨询常用的分析维度。
- **涉及文件**: `src/analyzers/emotion-dynamics.ts`（新建）、`src/views/AnalysisView.vue`

#### 9. 并排对比视图
- **需求来源**: PRD 3.5.1 对比视图
- **说明**: 新增一个页面或卡片，将双方的高频词、情绪分布、主动发起次数、平均回复时间并排对比展示。
- **价值**: 让双方差异一目了然，比分开的图表更直观。
- **涉及文件**: `src/views/AnalysisView.vue` 或新建 `src/views/ComparisonView.vue`

#### 10. 事件标记与里程碑
- **需求来源**: PRD 3.5.1 关系时间轴
- **说明**: 在时间轴上自动标记关键事件（情绪极值点、争吵爆发、长时间沉默结束），并允许用户手动添加里程碑（如"第一次约会"、"吵架和好"）。
- **价值**: 让时间轴从"数据曲线"变成"关系故事线"。
- **涉及文件**: `src/views/TimelineView.vue`、`src/db/schema.ts`（新增 events 表）

### 2.3 技术债务与工程化

这些不直接面向用户，但影响长期维护性和性能。

#### 11. 单元测试覆盖
- **现状**: PROJECT_STATUS 标记为"未解决"
- **范围**: parsers（格式解析正确性）、analyzers（统计计算准确性）、identity（身份识别逻辑）
- **工具**: Vitest
- **优先级**: 中。在分析维度稳定后补充，避免频繁改需求导致测试作废。

#### 12. 数据库迁移机制
- **现状**: PROJECT_STATUS 标记为"未解决"
- **说明**: Dexie.js 支持版本迁移。当前 schema 为 v1，未来新增字段/表时需要迁移脚本。
- **涉及文件**: `src/db/schema.ts`
- **优先级**: 中。在需要改表结构前完成即可。

#### 13. ECharts 代码分割与懒加载
- **现状**: 生产包 2.3MB+，构建工具提示 chunk 过大
- **说明**: 将各视图的 ECharts 配置和组件改为按需加载（`import()`），非首屏图表延迟加载。
- **涉及文件**: `vite.config.ts`、`src/views/` 各图表页面
- **优先级**: 低。当前是桌面/Web 应用，2MB 在现代网络下可接受。

#### 14. 大数据性能优化
- **现状**: 消息列表分页 50 条，未做虚拟滚动
- **说明**:
  - 消息列表虚拟滚动（`vue-virtual-scroller`）
  - 导入大文件（>100MB）分块解析 + Web Worker
  - 图表数据点超过 1000 时降采样
- **优先级**: 低。当前用户场景下消息量通常几万条，IndexedDB 可承受。

### 2.4 长期愿景（Phase 3+）

#### 15. Electron 桌面端封装
- **说明**: 打包为桌面应用，可对接 WeFlow HTTP API（127.0.0.1:5031）直连读取微信数据库，无需手动导出文件。
- **依赖**: WeFlow 需先支持 HTTP API。
- **优先级**: 低。当前 Web 版已能跑通完整流程。

#### 16. 群聊分析模式
- **说明**: 多人身份识别、群体情绪趋势、"潜水王"/"话痨"排行、小团体分析。
- **优先级**: 低。PRD 中主要定位一对一关系分析。

#### 17. 情感账户（积分模型）
- **说明**: 正向互动 +1 分（关心、赞美、及时回复），负向互动 -1 分（敷衍、延迟、争吵）。展示双方的情感账户余额变化。
- **优先级**: 低。概念有趣，但规则设计复杂，容易失真。

## 四、与竞品差异化对照

| 维度 | ChatLab | WeFlow | ChatMind 当前 | ChatMind 目标 |
|------|---------|--------|---------------|---------------|

## 五、结论

当前 v0.2.0 已覆盖 MVP 全部核心功能和 Phase 2 的大部分增强功能。**下一个版本建议聚焦"让 AI 分析更智能、让数据洞察更精准"**：

1. **消息情绪修正**（用户参与校准）
2. **关系阶段判定**（核心差异化标签）
3. **AI Function Calling**（动态查询而非静态摘要）
4. **AI 回答可溯源**（补齐可溯源卖点）

这四项完成后，ChatMind 将从"数据展示工具"升级为"真正的 AI 关系分析师"。
